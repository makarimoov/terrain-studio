Источник рельефа

PNG/JPEG в оттенках серого: яркость пикселя = высота. Можно перетащить файл прямо на 3D-сцену.

Клик по карте — выбрать центр, маркер можно перетащить. Рамка показывает охват (поле «Охват, град.»).

Бесплатное API Open-Meteo (данные SRTM, ~90 м на точку). Пример — окрестности Астаны.
